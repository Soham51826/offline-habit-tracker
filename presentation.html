Problem Statement & Motivation

The systemic failures of cloud-dependent habit applications
The Core Problem
⚠️
Cloud Lock-in & Privacy
Personal habits — mental health, medication, sleep — constitute sensitive human telemetry that should never leave the device.
  • Apps mandate cloud logins & embedded analytics SDKs.
  • Routines stored on remote third-party ad servers.
  • Vulnerable to data breaches and policy changes.
📶
Offline Fragility & Latency
Routine check-ins happen during transit, gym basements, or offline flights — precisely where cloud apps fail users.
  • Cloud apps stall with loading spinners without Wi-Fi.
  • Network latency disrupts seamless one-tap check-ins.
  • Sync conflicts frequently erase active streak data.
🧠
Passive Checkboxes, No Guidance
Traditional trackers are dumb digital checklists — no psychological intelligence, no situational awareness.
  • No detection of weekend drops or cognitive burnout.
  • Lack actionable nudges like habit stacking or scaling.
  • Users abandon once a single streak breaks.

Proposed Solution: The Offline Cognitive Companion

Three pillars of autonomous local habit engineering
System Vision
🛡️
1. Absolute Local Sovereignty
Zero reliance on remote servers, external APIs, or authentication barriers of any kind.
  • Embedded SQLite stores 100% of data on-device.
  • Sub-millisecond read/write on every habit toggle.
  • Zero battery drain from background network polling.
🔬
2. Rule-Based Behavioral Engine
Deterministic local implementation of established behavioral psychology frameworks.
  • James Clear: Habit Stacking — procedural coupling.
  • BJ Fogg B=MAP: Weekend slump & ability curves.
  • Kahneman: Loss Aversion — streak defense urgency.
⚙️
3. Background Guardian (WorkManager)
Autonomous background intelligence running within Android OS constraints.
  • Inspects SQLite logs opportunistically, screen off.
  • Dispatches streak defense alerts before midnight cutoff.
  • Ensures momentum never collapses unassisted.

SQLite Database Schema & Data Integrity

Relational tables, compound indexing, and cascade relationships in local storage
Data Layer · Aman
1. Core Relational Tables
TableKey ColumnsConstraints
habits id, title, category, color_value, target_count, reminder_time, anchor_habit_id PK (id) FK self-ref
habit_logs id, habit_id, date, status, value, notes, logged_at, mood_score PK FK habit_id
UNIQUE(habit_id,date)
behavioral_insights id, habit_id, type, title, message, actionable_step, severity, is_dismissed PK (id)
The UNIQUE(habit_id, date) constraint guarantees idempotency — rapid UI toggling never duplicates historical metrics.
2. Compound Indexing & Optimizations
High-performance indexes power real-time 30-day rolling charts and instant streak calculations.
-- Composite B-Tree Indexes CREATE INDEX idx_logs_habit_date ON habit_logs(habit_id, date); CREATE INDEX idx_logs_date ON habit_logs(date); CREATE INDEX idx_insights_dismissed ON behavioral_insights(is_dismissed);
  • ON DELETE CASCADE — Deleting a habit cleanly purges all logs and insights automatically.
  • 28-day heatmap loads in <4ms from cold SQLite cache.

Background Services & Android WorkManager

Battery-friendly autonomous streak protection within modern Android OS constraints
Android System · Aman
Android WorkManager Integration
Android 12+ restricts background execution via Doze mode & App Standby Buckets. Traditional AlarmManager timers get killed by the OS.
// Background Isolate Entry Point @pragma('vm:entry-point') void callbackDispatcher() { Workmanager().executeTask((task, data) async { final db = DatabaseHelper.instance; final pending = await db.getPendingHabitsToday(); // Streak defense: active streak >= 3 & time >= 18:00 if (now.hour >= 18 && pending.isNotEmpty) { await NotificationService.instance.show( title: '🛡️ Streak Defense Alert', body: 'Keep your momentum alive!', ); } return Future.value(true); }); }
Notification Architecture
  • High-Importance Channel — habit_reminders_channel with custom vibration.
  • Android 13/14+ Permissions — Graceful runtime POST_NOTIFICATIONS request flow.
  • Battery Constraints — NetworkType.not_required for opportunistic execution.
Streak Defense Logic
If an active streak of 3+ days has not been logged by 6:00 PM, the background worker triggers a high-urgency loss-aversion prompt — ensuring user momentum never collapses silently.

Rule-Based Behavioral Analytics Engine

Translating behavioral science into local deterministic heuristics
Behavioral Science · Arsh
🔗
1. Habit Stacking
James Clear — Atomic Habits.
Couples a struggling habit (<60%) with an anchor habit (>75%).
"After Morning Espresso, do 5-min Journaling."
📉
2. Weekend Slump
BJ Fogg — Tiny Habits.
Detects when weekend adherence drops >25% vs weekdays.
"Adopt a Minimum Viable Habit — reduce weekend requirement by 75%."
⏰
3. Circadian Friction
Roy Baumeister — Ego Depletion.
Analyzes hourly timestamps to find energy depletion windows.
"Morning workouts: 90% success. Evening: 65% failure. Shift timing."
🛡️
4. Never Miss Twice
Identity Protection.
Missing one day is an accident; two days begins a negative loop.
"High-priority morning recovery intervention triggered automatically."
